# Casino Investigator
A machine learning project that investigates whether a casino game is fair or unfair based on statistical outcomes.

Currently simulates a roulette wheel that can be biased or unbiased, extracts statistical features from the results, and trains machine learning models to distinguish and recognise a cheating casino game. 


## Features
- Simulates fair and biased casino game outcomes
- Generates labelled data features for machine learning
- Supports multiple type of outcome biases
- Trains supervised machine learning classification models
- Evaluates model performance across different cheating methods 

## Technologies
- Python
- scikit-learn
- pandas
